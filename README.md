# Lightning in the Air Website

Public pages:
- Home
- The Band
- Shows, including upcoming dates and past performances
- Media with embedded YouTube videos and a photo gallery
- Booking

The public site reads content from Firebase when configured and falls back to `data/site-content.json` before Firebase is connected. The `/admin/` area is intentionally not linked from the public website and is marked noindex.

See `FIREBASE-SETUP.md` for the future admin and storage connection steps.
