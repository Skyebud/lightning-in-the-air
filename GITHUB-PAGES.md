# Fast GitHub Pages Checklist

1. Create a public GitHub repository named `lightning-in-the-air`.
2. Upload everything in this folder to the repository root.
3. Confirm `index.html` is visible at the top level of the repository.
4. Open **Settings → Pages**.
5. Set source to **Deploy from a branch**.
6. Select **main** and **/ (root)**.
7. Save and wait for the published URL.

Expected URL format:

`https://YOUR-USERNAME.github.io/lightning-in-the-air/`

Do not place all files inside a second nested `lightning-in-the-air-site-v2` folder in the repository. `index.html` must be at the repository root.
